Context & Problem

Administrative Bottlenecks at PCU Choir

PCU Choir is a high-intensity student activity unit (70-80 active members, 10+ major annual events). Managing these activities manually resulted in operational inefficiencies:

Manual Fragmented Processes

Coordination was scattered across WhatsApp copy-paste lists, Google Drive, Excel, and paper sheets. This led to delays and loss of historical activity data.

Key Core Problems

  • Attendance Vulnerabilities: Paper attendance sign-sheets were prone to proxy checking (titip absen), signatures were hard to read, and manual validation was slow.
  • Uncataloged Music Sheets: Physical storage and Google Drive directories lacked metadata catalogs (SATB, Genre, etc.), making score discovery difficult.
  • Delayed SKKK Validation: Calculating attendance percentages manually took up to 40 minutes per event, leading to a 1-2 week delay in student credit reports.
Research Questions

Defining the Scientific & Operational Objectives

RESEARCH QUESTION 1

How can an integrated MIS improve the time-efficiency of administrative tasks at PCU Choir?

RESEARCH QUESTION 2

To what extent does a dynamic QR-based attendance module secure data and accelerate check-ins?

RESEARCH QUESTION 3

How does automated reporting affect validation speeds and accuracy of student activity (SKKK) reports?

Scope of Research

System Limitations

  • Target Users: Fungsionaris (Web Admin Panel) and Active Members of PCU Choir (Mobile App).
  • Input Boundaries: Member profiles, Event scheduling, Practice rosters, dynamic QR scan codes, and PDF sheets. (Excludes financial records and inventory).
  • Technical constraints: Uses custom internal REST APIs; does not include advanced algorithms (ML) or third-party SSO integrations.
Proposed System Design

PCU Choir Integrated Management System

React Web Admin Panel

For Fungsionaris / Admins

Enables full management of members, schedules (routine vs event), sheet music catalogs, dynamic QR generation, participant status locking, and instant PDF exports of SKKK records.

Flutter Mobile Application

For Active Choir Members

Enables members to self-register for upcoming events, view schedule calendar details via popover, scan dynamic practice QR codes, and preview score sheets directly inside a PDF viewer.

Secure Node.js & SQL Server

REST API & Core Database

Uses JWT authentication, dynamic QR rotation intervals, real-time silent socket sync, and automatic attendance list initialization built on SQL Server index optimization.

Wrap Up

Conclusion

  • Proven Administrative Efficiency: The integrated system is 33.775 times faster than manual processes on average. Full UAT pass rate reached 100% with an error rate of 0%.
